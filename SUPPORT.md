## 3. Filing Issues vs. Security Reports

| Topic | Where to Go |
| :--- | :--- |
| **Bug Report** | Open a [GitHub Bug Report](https://github.com/CardSorting/HEAV3NS-PUBLISHING/issues/new?template=bug_report.md) |
| **Feature Request / Enhancement** | Open a [GitHub Feature Request](https://github.com/CardSorting/HEAV3NS-PUBLISHING/issues/new?template=feature_request.md) |
| **Pull Request / Code Contribution** | Read [CONTRIBUTING.md](./CONTRIBUTING.md) and open a Pull Request |
| **Security Vulnerability** | **Do not open a public issue.** Follow [SECURITY.md](./SECURITY.md) |
