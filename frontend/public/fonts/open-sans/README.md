# Bundled Open Sans

Unmodified Open Sans v44 WOFF2 files from the Google Fonts CSS API, retrieved
2026-10-15. Licensed under the included [SIL Open Font License](OFL.txt).

Source: https://fonts.googleapis.com/css2?family=Open+Sans:wght@300..700&display=swap
License: https://github.com/googlefonts/opensans/blob/main/OFL.txt

`public/css/fonts/open-sans.css` retains the upstream Unicode subsets, normal
style, and variable weight range 300–700. Browsers download only the subsets used
on the page. Italics are synthesized, matching the existing Google font request.
Filenames include a content hash to avoid stale font caches after asset updates.
The older sibling TTF files remain in use for server-side watermark generation.
